# Chat Rule Watcher — клиент хелпера

Это клиентская версия для **одного хелпера**. Устанавливается только на его Minecraft-клиент в папку `mods`. На сервер ничего устанавливать не нужно, другим игрокам мод не нужен.

Мод анализирует входящие сообщения публичного чата, и если находит совпадение с одним из правил 3.1–3.3, 3.5–3.10, выводит хелперу локальное уведомление прямо в игровой чат. Уведомление не отправляется другим игрокам.

## Сборка
Нужны Java 21 и Gradle. Выполнить в папке проекта:

```sh
gradle build
```

JAR появится в `build/libs/ChatRuleWatcher-HelperClient-1.0.0.jar`.

## Важно
- Мод видит только сообщения, которые сервер действительно отправил этому клиенту и которые отображаются в публичном чате.
- Он не может прочитать сообщения из приватных каналов/личных сообщений, скрытые сервером или не доставленные клиенту.
- Фильтр основан на ключевых словах и эвристиках: возможны ложные срабатывания и пропуски.
- Правило 3.4 (флуд/повторы) в этой версии не отслеживается, потому что клиентское событие содержит только уже доставленные сообщения, а серверная антифлуд-проверка была частью серверной версии.
